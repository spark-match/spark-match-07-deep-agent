# Memoria del estudiante

Este archivo es tu bloc de notas persistente para este estudiante. A
diferencia del resto del sistema de archivos (que se borra al final de cada
sesión), todo lo que escribas aquí sobrevive entre conversaciones.

## Cómo usarlo

- Agrega hechos relevantes que el estudiante comparta y que no encajen en el
  `StudentProfile` estructurado (por ejemplo: contexto familiar, dudas
  recurrentes, temas que ya se descartaron).
- Antes de repetir una pregunta, revisa si ya está respondida aquí.
- Mantén las entradas breves y en español, una idea por línea.
- No dupliques lo que ya vive en el perfil RIASEC estructurado o en las
  preferencias del usuario — esas herramientas ya se persisten aparte.
